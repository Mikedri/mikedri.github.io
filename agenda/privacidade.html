Política de Privacidade — Agenda NEW CONT

Última atualização: 19 de outubro de 2026.

1. Quem somos

A Agenda NEW CONT é um aplicativo de uso pessoal de Mike Elvis Pellegrini, da NEW CONT Assessoria Empresarial Ltda. (Travessa Marajó, 31, Santo André/SP). Contato: mikenewcont@gmail.com.

2. Quais dados o aplicativo acessa

Com a autorização do usuário, o aplicativo acessa a lista de agendas e os compromissos do Google Agenda (permissão de leitura e gravação de agenda) e do Outlook/Microsoft 365, além do endereço de e-mail da conta conectada.

3. Como os dados são usados

Os dados são usados exclusivamente para exibir os compromissos na tela do aplicativo e para criar, alterar, excluir ou responder compromissos quando o próprio usuário pede.

4. Onde os dados ficam

O aplicativo roda no computador do usuário. As autorizações de acesso e uma cópia temporária dos compromissos ficam gravadas apenas nesse computador. Nenhum dado é enviado a servidores da NEW CONT ou de terceiros, vendido, compartilhado ou usado para publicidade.

5. Uso limitado dos dados do Google

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar o acesso

O usuário pode desconectar as contas a qualquer momento pelo botão "Desconectar" do aplicativo, ou revogar o acesso em myaccount.google.com/permissions (Google) e myapps.microsoft.com (Microsoft). Desinstalar o aplicativo apaga os dados guardados no computador.

7. Contato

Dúvidas sobre esta política: mikenewcont@gmail.com.
